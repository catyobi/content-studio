# content-studio
AI-assisted content editing platform for small businesses. Authentic content, intelligent production.

## Local video engine prototype

Select five original clips, choose branding and audio, and export a 25–30 second vertical MP4. The editor runs on your own computer; there are no accounts or external rendering services.

Follow the [Apple Silicon setup and usage guide](docs/video-engine.md). The [technical feasibility study](docs/technical-feasibility.md) describes the renderer design and acceptance criteria.
